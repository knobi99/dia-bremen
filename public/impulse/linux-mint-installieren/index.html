Linux Mint installieren – einfach erklärt

März 30, 2026

Linux Mint ist eine kostenlose, sichere und benutzerfreundliche Alternative zu Windows. Diese Anleitung zeigt, wie Sie es Schritt für Schritt installieren – ganz ohne Vorkenntnisse.

Vorbereitung

Bevor es losgeht, brauchen Sie Folgendes:

  • Einen USB-Stick mit mindestens 8 GB Speicher
  • Einen Computer oder Laptop

Wichtig: Sichern Sie vorher alle wichtigen Daten (Fotos, Dokumente) auf einem externen Speicher oder USB-Stick.

Schritt 1: Linux Mint herunterladen

Laden Sie die aktuelle Version Linux Mint Cinnamon herunter.

Schritt 2: Bootfähigen USB-Stick erstellen

  1. USB-Stick einstecken
  2. balenaEtcher herunterladen und öffnen
  3. ISO-Datei auswählen
  4. USB-Stick auswählen
  5. Auf „Flash“ klicken

Schritt 3: Vom USB-Stick starten

Starten Sie den Computer neu und öffnen Sie das Boot-Menü.

Mögliche Tasten:

F12 · F2 · ESC · DEL

Schritt 4: Linux Mint installieren

  1. Deutsch auswählen
  2. Tastatur Deutsch
  3. WLAN verbinden
  4. Festplatte löschen und Linux Mint installieren
  5. Zeitzone Berlin
  6. Benutzername und Passwort festlegen
  7. Jetzt installieren

Schritt 5: Abschluss

Nach der Installation den USB-Stick entfernen und den Rechner neu starten.

Wichtige Hinweise

  • Computer während der Installation nicht ausschalten
  • Internetverbindung ist hilfreich
  • Bei Problemen einfach erneut beginnen

Nach der Installation

Empfehlenswert:

  • Updates installieren
  • LibreOffice installieren
  • VLC installieren
